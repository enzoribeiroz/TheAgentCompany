## ⚠️ Note About Cloudflared URLs

Cloudflared free tunnels:
- ✅ No interstitial page (unlike ngrok)
- ⚠️ URL changes each time you restart
- ⚠️ May stop working after several hours
- ✅ Can be restarted anytime

If the URL stops working later:
```bash
# Restart tunnel and get new URL
cd /tmp
pkill cloudflared
nohup ./cloudflared tunnel --url http://localhost:8080 > cloudflared.log 2>&1 &
sleep 5
grep "https://" cloudflared.log | tail -1
```
